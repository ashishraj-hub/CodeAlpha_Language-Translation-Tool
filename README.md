# 🌐 Language Translation Tool

A professional Python application designed to translate text between multiple languages with a clean **GUI interface**.

---

## ✨ Key Features
- 🖥️ **Intuitive GUI** built with Tkinter  
- 🌍 **Multi-language support** using translation APIs (Google Translate / Microsoft Translator)  
- ⚡ **Real-time translation** with instant results  
- 📋 **Copy to clipboard** functionality  
- 🔊 **Text-to-speech** option for accessibility  

---

## 🛠️ Tech Stack
- **Python 3.x**  
- **Tkinter** → GUI framework  
- **googletrans / Microsoft Translator API** → Translation engine  
- **pyttsx3** → Text-to-speech 

---

## 🚀 Getting Started

### Prerequisites
- Install Python 3.x    
- Install dependencies:
  ```bash
  pip install googletrans==4.0.0-rc1
  pip install pyttsx3 gtts
  ```
  1.Clone the repository
  ```bash
  git clone https://github.com/ashishraj-hub/CodeAlpha_Language-Translation-Tool.git
  ```
  2.Navigate into the project folder:
  ```bash
  cd CodeAlpha_Language-Translation-Tool
  ```
  3.Run the application:
  ```bash
  python Language_Translator.py
  ```

## 🎯 Usage

1.Launch the app.

2.Enter text in the input field.

3.Select source and target languages.

4.Click Translate to view results.

5.Use Copy or Speak buttons for extra functionality
